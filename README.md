# 📈 End-to-End Superstore Sales & Customer Insights Capstone

## Executive Summary
This capstone project delivers an end-to-end data analytics workflow—from raw data ingestion, missing value imputation, and feature engineering to SQL analytical modeling, exploratory data analysis, and an interactive Streamlit executive dashboard.

## Deliverables Included
1. **Raw Dataset:** `data/raw_superstore.csv`
2. **Cleaned Dataset:** `data/cleaned_superstore.csv`
3. **Data Cleaning Script:** `generate_data.py`
4. **SQL Analysis Script:** `sql_analysis.py` & `sql_queries.sql`
5. **Interactive Dashboard:** `app.py`
6. **8 Core KPIs:** Gross Revenue, Net Revenue, Total Profit, Avg Profit Margin, Total Orders, Units Sold, Avg CSAT Score, Return Rate.

## Presentation Outline & Technical Details
* **Pipeline:** Ingested raw sales data, performed median/mode imputation, engineered net revenue & profit margins, analyzed regional trends using SQL, and visualized insights on Streamlit.
* **KPI Strategy:** Tracked top-line business metrics alongside operational/customer health indicators.
