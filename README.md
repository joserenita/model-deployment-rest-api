# Day 10 Capstone Project: End-to-End Data Analytics & Interactive Dashboard

## Project Overview
This project presents a complete data analytics solution built on superstore transaction data, covering data extraction, cleaning, feature engineering, SQL analysis, and an interactive Streamlit dashboard.

## Key Features & Deliverables
* **Data Processing:** Missing value handling, median/mode imputation, and feature engineering (`Net_Revenue`, `Profit_Margin`).
* **SQL Integration:** In-memory SQLite analytics assessing discount impact and regional performance.
* **Interactive Dashboard:** 8 core KPIs alongside dynamic filtering and Plotly visual breakdowns.
* **Documentation:** Presentation outline and technical Q&A guidelines.
